# 书架页：清单格式、扫描规则与生成

多本书、多段速读稿的统一入口页**不由模型手写**。各段照常跑 `build_html.py`
得到独立的 `速读稿.html` / `衔接包.html`，再用 `build_shelf.py` 生成一张书架页：

```bash
python3 scripts/build_shelf.py --manifest 阅读工作区/书架.md
# → 阅读工作区/书架.html
```

书架页**不合并任何正文**：一个书架有多本书，一本书可以有多个速读稿（各负责
一部分章节），每张卡片是一个相对链接，点击跳到对应速读稿。各册 HTML 仍是
独立文件，单册更新后重跑本脚本即可刷新统计。

## 一、两种收录方式

### 1. 书架.md 清单（推荐，顺序与文案可控）

```markdown
# 我的速读书架

## 《凡人修仙传》
忘语 · 修仙 · 主线速读

- 第1–320章：凡人修仙传/第1-320章/速读稿.html
- 第321–640章：凡人修仙传/第321-640章/速读稿.html
- 第641–960章：凡人修仙传/第641-960章/速读稿.html

## 《诡秘之主》
爱潜水的乌贼 · 西幻

- [卷一 小丑](诡秘之主/卷一/速读稿.html)
- 卷二衔接：诡秘之主/卷二/衔接包.html
```

| 位置 | 写法 | 用途 |
|---|---|---|
| 一级标题 | `# 我的速读书架` | 书架页标题（可用 `--title` 覆盖） |
| 二级标题 | `## 《书名》` | 一本书；`《》` 可省略，封面与搜索自动拆用 |
| 标题下的说明行 | `忘语 · 修仙` | 书的简介（可多行，也可不写） |
| 列表条目 | `- 册名：相对路径/速读稿.html` | 一份速读稿 = 一张卡片 |

条目三种写法都认：`[册名](路径)`、`册名：路径`（分隔符 `：` `:` `｜` `|`）、
裸路径。路径**相对于 书架.md 所在目录**书写，但最终链接按**输出 HTML 所在
目录**换算——清单和书架页不在一处时链接也不会断；也接受 `https?://` 外链
（能跳转，但读不到统计与进度）。

- 册名建议写成章号范围（`第641–960章`）或卷名（`卷二 魔术师`）；只写范围时
  卡片标题自动改用目标阅读器的 `<title>`。
- **清单顺序就是展示顺序**，脚本不重排。
- 条目指向的文件不存在时：卡片保留、降级显示「⚠ 目标文件缺失」，并打告警——
  先跑 `build_html.py`，不要改脚本来迁就。

### 2. 目录扫描（不给清单时）

```bash
python3 scripts/build_shelf.py --root 阅读工作区 --out 阅读工作区/书架.html
```

- 递归查找 `速读稿.html` / `衔接包.html`；一个都找不到时，退一步把**带
  `page-data` 标记**的 html（即本工具链生成的阅读器，哪怕改了名）也收进来。
- 归组规则：标题里有 `《书名》` 按书名归组；否则按一级子目录归组；散在根目录
  的文件归成一本（书名取标题里的《书名》或根目录名）。
- 册的排序按章号范围起点 → 目录名自然序自动排。
- `书架.html` 自身不会被收进书架。

## 二、卡片与页面里可用的东西

- **卡片**：册号、章号范围、`单元 N · 可跳转 N 章 · N 人` 统计、衔接包标记。
  统计与标题从目标阅读器内嵌的 `page-data` 自动读取，无需在清单里重复维护。
- **书**：CSS 书脊封面（按书名取色，无外部图片）、简介、`N 册 · 约 N 章`；
  点书头可折叠/展开。
- **搜索**：按书名 / 册名 / 章号过滤（`/` 聚焦，`Esc` 清空）；搜到书时整本
  连同所有册一起显示。
- **阅读进度角标**：目标阅读器带进度键（`build_html.py` 生成），书架页在同源
  （GitHub Pages、本地 http 服务）下能读到各册进度——卡片右上角出现丝带
  书签并显示「读到 N%」/「已读完 ✓」，顶栏出现「继续阅读 →」直达最近在读
  的一册。`file://` 直接双击打开时多数浏览器不允许跨文件读 localStorage，
  角标自动隐藏，其余功能不受影响。
- **响应式**：宽屏每行多张卡片，窄屏（≤720px）自动单列、封面收窄；深色主题
  跟随系统，`◐` 手动切换的结果与单书阅读器共用同一个偏好键。
- **离线**：单文件、零外链；连同各册 HTML 一起拷走即可整个书架离线使用。

## 三、常用参数

```bash
python3 scripts/build_shelf.py \
    --manifest 阅读工作区/书架.md \
    --out 阅读工作区/书架.html \
    --title "我的速读书架" [--json]
```

| 参数 | 说明 |
|---|---|
| `--manifest` | 书架.md；不给 `--manifest`/`--root` 时自动找当前目录的 `书架.md`，找不到退化为扫描当前目录 |
| `--root` | 扫描根目录（与 `--manifest` 二选一，显式指定者优先） |
| `--out` | 输出 html，默认 `书架.html`（写在清单/根目录旁） |
| `--title` | 书架标题，默认取清单 H1 或「速读书架」 |
| `--json` | 机器可读输出（书数、册数、章数、告警），给上层脚本吃 |

## 四、生成后的自检

```
✅ 书架已生成：阅读工作区/书架.html（15 KB）
   2 本书 · 5 份速读稿 · 约 961 章
   ⚠️ 「凡人修仙传」指向的文件不存在：凡人修仙传/第641-960章/速读稿.html
      （先跑 build_html.py 生成，或检查相对路径）
```

| 告警 | 含义 | 处理 |
|---|---|---|
| 指向的文件不存在 | 清单里有条目还没生成 HTML | 对该段跑 `build_html.py`，或修正相对路径 |
| 下面没有可用的速读稿条目 | 书的条目都不是 `路径.html` 写法 | 按「册名：路径」格式补条目 |
| 没解析到任何书 | 清单里没有 `## 书名` 标题 | 每本书一个二级标题 |
| 没找到任何速读稿 HTML | 扫描模式下目录里没有成品 | 先跑 `build_html.py`，或改用清单模式 |

要交付给用户时，把 `书架.html` 连同各册速读稿 HTML 一起发；托管到 GitHub
Pages 等同源环境还能点亮进度角标。
