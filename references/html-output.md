# HTML 速读页：输入契约与生成

速读稿的 HTML 版**不由模型手写**。模型只按体例产出 markdown，渲染交给脚本：

```bash
python3 scripts/build_html.py --digest 第X-Y章/速读稿.md
# → 同目录 速读稿.html（单文件、零外链、约 30–80 KB）
```

## 一、脚本要求的最小契约

三份输入，前两份来自流水线本身，第三份是既有的分章索引。

### 1. 速读稿.md（必需）

| 位置 | 写法 | 用途 |
|---|---|---|
| 一级标题 | `# 《书名》速读稿（第X–Y章）` | 页面标题 |
| 单元标题 | `## 单元01｜入书院与试炼结怨（第1583–1590章）` | 侧栏导航项 + 章号→单元映射 |
| 原文切片 | `**【原文·第1583章 狗死了】**` 后跟 `> 「…」` | 章节速查锚点、正文引文块 |
| 其他 | `**【重要】**`、`**【过渡】**`、`**这一段结束时**`、表格、`---` | 各自独立样式 |

- 单元编号可写阿拉伯数字或中文数字（`单元01` / `单元一` 都认）。
- 括号里的章号区间用于「章节速查」跳到单元级；有切片的章直接跳到切片。
- 不写单元标题也能跑：整份文档会被当成一个单元，导航仍在。
- `## 读完索引` 这类非「单元」的二级标题会自动归入侧栏的「总览 / 附录」组，不会丢。

### 2. 人物档案.md（做人物链接与详情）

```markdown
## 别名归一表

| 本名 | 首次出现 | 马甲/尊称 | 身份势力 |
|---|---|---|---|
| 沈砚 | 第1583章 狗死了 | 沈师弟、砚哥 | 归墟书院内院 |

## 人物

### 沈砚
- 身份：…
```

- **表头必须含「本名」**（别名列识别：马甲／尊称／别名／别称），别名列用 `、` `,` `/` 分隔。
- 单元格里的 `**加粗**`（如 `| **韩立** | **韩道友／韩兄** | … |`）与「（第1292章 石柳等称）」这类括号说明会被自动剥离，不用为了脚本去手工去掉格式。
- 详情条目用 `### 人名`（人名需命中别名表）；`### ` 以下内容原样渲染进人物抽屉。
- 正文里出现的别名会自动链到本名条目；**默认每个单元只链第一次**，加 `--link-all` 可全链。

### 3. chapters.tsv（做章节速查）

首行表头含 `idx` 与 `title`（即 `章节索引` 导出的原表），例如：

```
idx	title	chars	start	end
1583	第1583章 狗死了	1000	0	1000
```

没有它也能生成，只是「章节速查」只列有切片的章。脚本会按 `速读稿同目录 → 上级目录` 顺序自动找 `chapters.tsv` / `章节索引.tsv`，`人物档案.md` 同理，都无需显式传参。

## 二、页面里可用的东西

- **单元导航**（左侧，宽屏常驻／窄屏抽屉）：单元列表、总览附录、章节速查（可按章号或章名筛选）、人物索引。
- **人物链接**：正文人名可点，弹出该人物的《人物档案》条目；窄屏是从底部升起的抽屉。
- **字号调节**：顶栏 `A-` / `A+` 缩放正文字号（0.8–1.6 倍），选择记在 `localStorage` 里，跨段通用。
- **阅读进度本地缓存**：`localStorage` 记录所在单元与滚动位置，刷新/重开自动回到原处；可按文件名区分（`--progress-key` 可换键），支持一键清除。
- **响应式**：宽屏左导航＋正文限宽排版，窄屏自动折叠导航、字号与行距相应放大；`data-theme` 支持跟随系统深色。
- **离线**：单文件、无外链、无 CDN，可直接丢进聊天窗口、网盘或手机浏览器。

## 三、常用参数

```bash
python3 scripts/build_html.py --digest 速读稿.md \
    --characters 人物档案.md --index chapters.tsv \
    --title "《凡人修仙传》速读稿" --out 速读稿.html \
    --progress-key fanren-1583-1678 [--link-all] [--json]
```

| 参数 | 说明 |
|---|---|
| `--digest` | 必需，速读稿 md |
| `--out` | 输出路径，默认同名 `.html` |
| `--characters` | 人物档案 md，默认自动找 |
| `--index` | chapters.tsv，默认自动找 |
| `--title` | 页面标题，默认取速读稿 H1 |
| `--progress-key` | 进度缓存键，默认取输出文件名（同一本书续段建议手动指定，可跨段合并进度） |
| `--link-all` | 每个人名都链接（默认每单元首次） |
| `--json` | 机器可读输出，`finalize.py` 用 |

## 四、生成后的自检（不占上下文）

脚本退出时会打印一行摘要并给出告警，例如：

```
✅ HTML 已生成：速读稿.html（28 KB）
   单元 2 · 可跳转章节 14 · 人物 4
```

告警三类，出现即按提示补料，不要改脚本来迁就：

| 告警 | 含义 | 处理 |
|---|---|---|
| 未找到《人物档案.md》 | 正文不会有人物链接 | 先产出人物档案，或 `--characters` 指路径 |
| 没解析到「别名归一表」 | 同上 | 检查表头是否有「本名」列 |
| 有别名表但没有人物条目 | 人名可点但无详情 | 补 `### 人名` 条目 |
| 没找到「【原文·第N章 章名】」切片 | 章节速查只能到单元级 | 按体例补切片 |

要交付给用户时，直接把 `速读稿.html` 作为文件发给用户（用你的文件交付工具，或给文件卡片）。
