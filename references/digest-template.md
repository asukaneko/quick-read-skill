# 速读稿模板（模式 A）

速读稿是**给用户读的成品**，不是给作者看的分析报告。它要能替代原著：读完知道发生了什么、为什么发生、谁和谁怎么了，重要的地方还能就地看原文。

一句话标准：**用户读完这份稿子再打开原著任意一章，不应该有"这是谁、他为什么在这"的时刻。**

---

## 整体骨架

```markdown
# 《书名》速读稿

> 按你的偏好整理。最想看：男女主线 / 关键转折｜已压缩：打斗招式、宗门日常。
> 这是删减版，某段没提到不代表原文没写；你随时可以让我把某段展开。

## 全书概览

- **一句话**：少年沈砚带着母亲的半枚青铜令拜入归墟书院，追查母亲之死，最终发现仇人是……
- **类型与基调**：仙侠 / 悬疑向 / 前三十章偏慢热
- **理解剧情必需的设定**：书院分三院、令纹对应宗门血脉、书院每十年"落榜"一批弟子（解释后文）
- **主要人物**：沈砚（主角，隐忍、认死理）｜苏晚（同门，医术，嘴硬心软）｜玄鹤真人（师父，藏事）｜赵乾（对头，赵家嫡子）
- **主线走向**：（按用户是否要结局决定写不写）

## 单元一：入书院与试炼结怨（第 1–15 章）

这段讲什么：沈砚靠母亲的令牌入学，在试炼中当众折了赵乾的面子，从此被处处针对；同时认识了唯一愿意替他说话的苏晚。

**【重要】**
沈砚入学靠的不是才学，是玄鹤真人认出了那半枚令牌……
试炼那场，作者重点不在打斗，在于沈砚用的是"母亲教的手法"——玄鹤真人看到后脸色变了（这是第一个信号：师父认识他母亲）。

**【过渡】**
第 8–11 章是同门日常与一次外出采药，信息量很小，只需知道两件事：沈砚开始跟着苏晚学辨药；赵乾在这期间摸清了沈砚的作息。这两件分别在第 12 章和第 14 章用上。

**【原文·第7章 狗死了】**
> 「沈砚把汤倒进碗里，蹲下身。那条黄狗凑过来，两口就舔干净了，然后开始抽搐。」

**【原文·第13章 试炼台上】**
> 「他一剑荡开赵乾的兵刃，台下没有一个人出声。」

**这一段结束时**：沈砚在书院站稳了脚但树了敌；苏晚与他从陌生变成"互相搭把手"；师父已经知道他母亲是谁，但没说；赵乾转入暗地。悬念：令牌上的纹样是什么意思（第 21 章揭晓）。
```

## 详略怎么分配

| 级别 | 在这一段里长什么样 |
|---|---|
| **S** | 展开写：动机、转折、代价、后果。可以写 2–5 段。配 1–3 条切片。 |
| **A** | 一段到两段，因果完整，不展开描写。 |
| **B** | 一句话到三句，形如「第 8–11 章是同门日常与采药，信息量很小，只需知道两件事：… ，这两件分别在第 12、14 章用上。」 |
| **C** | 合并进一句话并标出章号范围：「第 20–23 章是赶路与闭关，无实质推进，可以完全跳过。」 |

**注意 B/C 的写法**：不是"没什么可说的"，而是"压缩到最小但因果仍在"。用户原话是「虽然是不重要的，但还是要讲清来龙去脉」。

## 切片规则

- 只切 S 级，偶尔 A 级。名场面、转折对白、伏笔揭晓那句、人物定调句、结局句。
- 单条 80–500 字。中间可以用 `……` 省略，但**不允许改写、润色、翻译、合并句子**。
- 格式固定（脚本靠它校验和汇总）：

```markdown
【原文·第13章 试炼台上】
> 「他一剑荡开赵乾的兵刃，台下没有一个人出声。」
```

- 全书切片总量建议不超过原文的 15%。超了说明你在替用户"抄书"，不是速读，脚本也会告警。
- 写完跑：

```bash
python3 "$SKILL_DIR/scripts/verify_slices.py" --digest 速读稿.md --source 原文/ --index chapters.tsv --collect 原文切片.md
```

## 交付节奏

- 分单元写入文件，每 1–2 个单元落盘一次，并在对话里给一句进度（「单元二写完，主角已经出书院，接下来进京城篇」）。
- 超过 100 章的书，**先出第 1 个单元当样章**让用户确认详略口味，再全量推进。
- 全部写完后跑 `coverage_check.py`，确认没有静默漏章。
