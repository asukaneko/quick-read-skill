# 分章卡片模板

卡片是速读工作的**工作记忆**：后面的人物档案、伏笔账、状态快照、速读稿、衔接包全都从卡片长出来，而不是从原文重读。所以卡片的质量 = 最终产出的质量。

写卡片时只问一个问题：**这一章之后，故事的状态和上一章相比，多了什么、少了什么、变了什么？** 没变的东西不用写。

---

## 模板

```markdown
# 第0007章 夜里下药

- 字数：约 2,300
- 类型：S / A / B / C（对用户偏好的重要度，见 SKILL.md 分级表）

## 一句话
赵乾买通伙房，在沈砚的汤里下药；沈砚没喝，但因此发现了赵乾背后的靠山是谁。

## 因果链
- 因为第 3 章试炼上沈砚当众折了赵乾的面子 → 赵乾怀恨，开始找机会下手
- 于是买通伙房下药 → 药被沈砚察觉，倒给了看门狗，狗死了
- 结果：沈砚确认有人要害他，并在第 8 章顺着伙房查到「赵家」；赵乾从明面挑衅转为暗地下手

## 状态变化
- 沈砚：从"以为自己只是被同门排挤"→"确信有人要杀自己"，开始主动查
- 赵乾：从明面挑衅 → 转入暗地，且暴露了与赵家的关系
- 苏晚：本章从"对沈砚保持距离"→"发现狗死，替他瞒下此事"（关系第一次松动）

## 新信息 / 新设定
- 伙房管事老周是赵家的人（新人物，后续可能有用）
- 宗规：毒杀同门是死罪，但取证极难（为后文埋规则）

## 伏笔与悬念
- [新埋] 老周背后的赵家，与第 1 章令牌上的纹样同源（第 21 章揭晓）
- [回收] 第 3 章赵乾那句"你会后悔的"在此落到实处

## 原文切片
【原文·第7章 狗死了】
> 「沈砚把汤倒进碗里，蹲下身。那条黄狗凑过来，两口就舔干净了，然后开始抽搐。」
```

## 反面例子（常见错误都在这）

```markdown
# 第7章
赵乾给沈砚下药。沈砚发现了。苏晚帮了他。
```

问题：
- **只写事件，没写状态。** 读者看完不知道"现在沈砚知道什么、赵乾处于什么位置、苏晚和沈砚什么关系"。下一章他们突然联手，用户就懵了。
- **没有因果链。** "为什么是赵乾""为什么是现在"，用户接不上前文。
- **没有章号规范。** 后面引用时容易写错。
- **没有切片。** 关键画面流失，用户想看原句时找不到。
- **"苏晚帮了他"太糊。** 是当面帮、暗中帮、还是只是没揭发？这三者对后文的影响完全不同。

## 几个尺度问题

**一章可以只有 3 行。** 如果这一章是"主角赶路，遇雨，投宿，无事发生"，那卡片就写：`C 级。第 12 章，赶路投宿，为第 13 章到达青州做过渡，无状态变化。` 这就够了，而且必须有人写它——它是覆盖率的一部分。

**人物只记有变化的。** 张三这一章只是出现了一下说了句话，没推动任何东西，就不进"状态变化"栏。判断标准：这条变化会不会影响第 30 章？会，就写；不会，就不写。

**信息差要单独记。** 网文里最常见的断片是"主角已经知道真相了，跳读的人不知道"。所以卡片里凡是"某人得知了某件事"，一定要写清**是谁知道了、谁还不知道**。

**不确定就标。** 原文写得含糊（"那人似乎认识她"），卡片就写 `⚠️ 原文未明说`，不要替作者脑补成"他们认识"。

**切片单条 80–500 字。** 只切真正值得回看的：名场面、转折对白、伏笔揭晓句、人物定调句、结局句。格式必须是：

```markdown
【原文·第7章 狗死了】
> 「逐字原文，一个字都不要改。」
```

省略中间部分用 `……`，但不要改写。写完统一跑 `$SKILL_DIR/scripts/verify_slices.py` 校验。
