# 章节切分、编码与异常处理

`$SKILL_DIR/scripts/split_chapters.py` 负责把原文变成「可检索的文件 + 统一坐标」。索引一旦建立，**所有引用一律以 `章节索引.md` 的章号为准**，不要凭记忆编号——网文的卷/章编号经常分叉（第二卷重新从第 1 章开始），凭感觉编号必错。

---

## 它认哪些标题

按优先级依次尝试（`第X章` 那一类只要不是长句、不含句号，就认）：

| 格式 | 例子 |
|---|---|
| 中文章节 | `第12章 夜袭`、`第十二章 夜袭`、`【第12章】夜袭`、`第12回 夜袭`、`第12节` |
| 英文章节 | `Chapter 12`、`CHAPTER 12 A Door`、`Ch.12` |
| 编号标题 | `001. 夜袭`、`12、夜袭`、`12 夜袭` |
| 特殊章 | `序章`、`楔子`、`引子`、`前言`、`尾声`、`终章`、`后记`、`番外`、`外传` |
| 卷/部/篇 | `第一卷 风起`、`第2部 京城`（作为卷标记记入索引，不单独算章） |

自动跳过常见的盗版站广告行（`请收藏本站`、`更新最快`、`www.`、`笔趣阁`、`求月票`、`未完待续` 等），并把 3 个以上连续空行压掉。

---

## 标准用法

```bash
# 整本文件 → 索引 + 分章落盘
python3 "$SKILL_DIR/scripts/split_chapters.py" --input 全书.txt --outdir 阅读工作区/归墟行 --split

# 先看看能不能认出来，不写文件（推荐第一次都用它试探）
python3 "$SKILL_DIR/scripts/split_chapters.py" --input 全书.txt --dry-run

# 已经手动分好章了（用户粘贴后你逐章存盘），只建索引
python3 "$SKILL_DIR/scripts/split_chapters.py" --from-dir 阅读工作区/归墟行/原文 --outdir 阅读工作区/归墟行

# 指定编码 / 指定书名
python3 "$SKILL_DIR/scripts/split_chapters.py" --input 全书.txt --encoding gb18030 --book 归墟行
```

产物：

- `章节索引.md` —— 给人看的表（章号、标题、字数、卷）。
- `chapters.tsv` —— 给脚本看的：`idx / title / chars / start / end / file / volume`。
- `原文/第0001章_夜袭.txt` —— 仅 `--split` 时生成（文件名会自动去掉标题里重复的"第1章"前缀）。

`--json` 会输出结构化摘要（章数、总字数、编码、是否退化分块），需要判断是否识别成功时用它。

## 用户分批粘贴时的流程

长篇不要指望用户一次性给全。**每收到一批，立刻落盘**：

1. 把这一批按章写进 `原文/第0121章_xxx.txt`（章号按索引顺序补零，方便排序）。
2. 跑一次 `--from-dir`，索引会自动重建。
3. 之后**只读文件，不再回读对话里的原文**——对话会滚动、会被压缩，靠它记原文迟早出问题。

如果用户粘贴的内容没有章节标题，先问一句"这部分的章节是怎么分的"，或者临时用 `--chunk-size` 按字数切，但要在 `_进度.md` 里注明"该段为人工分块，非真实章节"，避免后面引用章号时出错。

## 异常处理速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 只识别出 1 章 / 识别为 0 章 | 标题格式不在内置规则里 | `--dry-run` 看原文标题长什么样，用 `--pattern` 指定正则 |
| 识别出几百个假章节 | 正文里有以「第X章」开头的句子 | 用更严格的正则，如 `--pattern '^第[0-9]+章[ 　]'` |
| 提示"退化为固定字数分块" | 完全没找到标题 | 确认文件是否真的是小说全文；必要时 `--pattern`；实在没有标题就接受分块，但引用时说明是分块编号 |
| 大量章节字数 < 200 | 误把某些行当成标题（例如目录行） | 看告警里列出的标题，改用更严格的 `--pattern`，或手动删掉目录部分后重切 |
| 乱码 | 编码不是 UTF-8 | `--encoding gb18030`（中文老 txt 几乎都是它）；脚本默认会按中文占比自动猜 |
| 卷与章编号重复 | 第二卷重新从第 1 章开始 | 索引里的 `idx` 是全局连续序号，**引用一律用 idx**，不要用原标题里的数字 |
| 一个文件里有好几本书 | 合集 | 先按书名切开，一本书一个工作区 |

### 自定义正则怎么写

`--pattern` 作用于**每行 strip 之后**的整行。有一组捕获组时会把它当标题；不写捕获组就用整行。

```bash
--pattern '^第[0-9]+章'                 # 只认阿拉伯数字章
--pattern '^【[^】]{1,20}】$'            # 标题形如 【夜袭】
--pattern '^={3,}.+={3,}$'             # 标题形如 ===夜袭===
--pattern '^(\d{1,4})[\.、]'            # 形如 001.夜袭
```

调正则时先用 `--dry-run`，它只打印识别结果、不写文件，试错成本几乎为零。

## 索引和其他脚本的配合

```
chapters.tsv ──> verify_slices.py   把切片定位到准确章号
             └─> coverage_check.py  找出"没被交代"的章
```

所以 `chapters.tsv` 是整条流水线的地基。**如果你重新切分了原文（换正则、换范围），一定要重跑索引，并重跑这两个校验**——否则校验结果会对不上，等于没校验。
